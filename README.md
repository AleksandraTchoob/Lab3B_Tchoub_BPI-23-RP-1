# Практическое задание 3Б: Справочник пользователей

## Описание
Интерактивное веб-приложение для загрузки и отображения данных пользователей и их публикаций с использованием публичного REST API (JSONPlaceholder).

## Как запустить
1. Распакуйте архив в любую папку.
2. Откройте файл `index.html` в любом современном браузере (двойной клик или через Live Server в VS Code).
3. Серверная часть не требуется, приложение работает полностью на стороне клиента.

## Результаты проверок (согласно заданию)
